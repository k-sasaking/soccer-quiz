# サッカークイズ

`soccer_knowledge.md` の内容から作った3択クイズ（全10問）を、ブラウザで解けるようにしたページです。

## 公開ページ

https://k-sasaking.github.io/soccer-quiz/

## 使い方

`index.html` をブラウザで開くだけで動きます（サーバー不要）。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページの骨組み（スタート／問題／結果の3画面） |
| `style.css` | 見た目（黒基調・スマホ対応） |
| `script.js` | クイズ10問のデータと出題ロジック |
| `クイズ.md` | クイズの元データ（問題・正解・解説） |
| `soccer_knowledge.md` | クイズの出典となる資料 |

## 仕様

- 1画面に1問ずつ表示します
- 答えを選ぶまで、正解も解説も表示しません
- 回答すると正誤の判定と、資料の出典つきの解説が出ます
- 1 / 2 / 3 キーでも回答できます
- 最後に正解数・正答率と全10問の振り返りを表示します

## クイズ内容を変更するとき

出題データは `script.js` の先頭にある `QUIZ` 配列に直接書いています。`クイズ.md` を更新したときは `script.js` も合わせて直してください。
