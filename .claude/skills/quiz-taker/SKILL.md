# クイズ出題

クイズ.md をもとに、1問ずつ出題する。

## 手順

1. クイズ.md を読む
2. 1問ずつ出題し、回答を待つ
   - 一度に複数問出さない
3. 回答後に正解と解説を言う
   - 解説には、資料のどこに書いてあるかを添える
4. 全問終わったら成績を発表する

## 出力

出題 →（回答後）正解と解説 → （次の問題...）→ 最後に成績（5問中〇問正解）

## やってはいけないこと

- 答えを先に言わない
