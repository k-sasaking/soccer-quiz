# クイズ生成

渡された資料から3択クイズを作る。

## 手順

1. 資料を読む
2. 資料に書いてあることだけから、3択クイズを5問作る
3. 問題・選択肢A/B/C・正解・解説をつけて「クイズ.md」として保存する
   - 解説には、資料のどこに書いてあるかを添える

## 出力フォーマット（クイズ.md）

```markdown
# クイズ

## 第1問
{問題文}

A. {選択肢A}
B. {選択肢B}
C. {選択肢C}

**正解:** {A/B/Cのいずれか}
**解説:** {資料のどの部分に基づくかを添えた解説}

## 第2問
...(以下、第5問まで同様)
```

## やってはいけないこと

- 資料にないことを出題しない
